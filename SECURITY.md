# Security Policy

Security fixes go into the latest release only.

Please don't open a public issue for security problems. Report them privately through
[GitHub private vulnerability reporting](https://github.com/coldwheel-dev/terraform-aws-pypi/security/advisories/new) with
what an attacker can do, steps to reproduce, and the module, Terraform/OpenTofu and AWS provider versions. You can expect a
first answer within 7 days.

Problems in the index itself (Lambda@Edge, CloudFront, S3) usually belong to the base module; report them the same way and
we'll handle both.
